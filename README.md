# Python Signal Generator

A Python program to generate and visualize basic waveforms using NumPy and Matplotlib.

## Features

- Generate sine waves
- Generate square waves
- Generate triangle waves
- User-defined frequency
- User-defined amplitude
- Visualize the generated waveform

## Technologies Used

- Python
- NumPy
- Matplotlib

## How to Run

Run `signal_generator.py` in Python or Spyder.

Enter the frequency and amplitude, then choose:

1. Sine Wave
2. Square Wave
3. Triangle Wave

## Output

The program generates and displays the selected waveform.
